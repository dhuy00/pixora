Product Requirements Document: Pixaura

A project-centric pixel art and frame-by-frame animation web application that unifies static drawing, non-destructive image-to-pixel conversion, and animation into a single distraction-free workspace, paired with a gallery-first creator community.

01 Product Vision and Goals

Unified Creative Workflow

Eliminate context switching by housing static drawing, frame-by-frame animation, and non-destructive image conversion inside a single project structure.

Low Friction, High Control

Allow guest and registered users to start drawing immediately with intuitive defaults while offering layer management, onion skinning, and custom palettes for experienced artists.

Gallery-First Community

Focus social features strictly on artwork discovery, appreciation, and creative inspiration rather than chat rooms, forums, or cluttered social feeds.

02 Target Users

Segment Description Core Needs
Hobbyist & Beginner Pixel Artists Casual creators learning pixel art or making avatars and icons. Clean UI, preset canvas sizes, image-to-pixel starting points, easy PNG/GIF export.
Indie Game Developers & Animators Creators building 2D game sprites, tiles, and frame-by-frame animations. Layer support, frame timing control, onion skinning, sprite sheet export, custom palettes.
Pixel Art Enthusiasts Community members who browse, collect inspiration, and support artists. Tag/category filtering, crisp artwork detail views, bookmarks, and creator following.

03 Core Features and Functional Requirements

3.1 Pixel Art Editor

Core Studio
What It Does
Provides a grid-based raster canvas for creating and editing multi-layer pixel artwork.
What Users Can Do
  • Create a project from preset dimensions (16x16, 32x32, 64x64, 128x128) or custom dimensions.
  • Draw with core tools: Pencil (1–8px), Eraser, Fill Bucket (contiguous or global), Eyedropper, and Shape Tools (Line, Rectangle, Circle — outlined or filled).
  • Manage colors via an active palette: add/remove swatches, pick custom Hex/RGB/HSL values, and switch preset palettes.
  • Navigate via Zoom (100%–6400%), Pan (spacebar + drag / middle-click), Pixel Grid Toggle, and a floating 1x/2x live Mini-Preview window.
  • Manage layers: create, rename, duplicate, delete, reorder, toggle visibility, lock, and adjust opacity (0–100%).
  • Undo and Redo actions across drawing and layer operations.
  • Save project state (cloud save for logged-in users; local browser storage for guests) and export PNG at integer scales (1x, 2x, 4x, 8x, 16x).
Expected Behavior
  • Drawing operations apply strictly to the currently selected unlocked, visible layer of the active frame.
  • Shape tools render a live pixel-perfect preview overlay while dragging and commit pixels on pointer release.
  • Exports scale using nearest-neighbor interpolation with zero blurring or anti-aliasing.
Constraints & Rules
  • Canvas width & height: min 8px, max 512px per dimension.
  • Maximum layers per project: 16.
  • Undo/Redo history stack: minimum 50 sequential actions per session.
  • Palette limit: 256 colors per project palette.

3.2 Animation Editor

Core Studio
What It Does
Extends the Pixel Art Editor with a collapsible timeline drawer for frame-by-frame animation and playback.
What Users Can Do
  • Toggle the animation timeline drawer inside the editor without leaving the project.
  • Add blank frames, duplicate existing frames, delete frames, and drag-and-drop to reorder frames.
  • Adjust global playback speed (FPS) and set per-frame duration overrides in milliseconds.
  • Enable Onion Skinning to display translucent overlays of adjacent frames (1–3 frames backward/forward).
  • Play, pause, loop (forward, ping-pong, once), and scrub through frames in real time.
  • Export animations as an animated GIF or a PNG Sprite Sheet (horizontal strip, vertical strip, or grid).
Expected Behavior
  • Layer hierarchy is shared across all frames, while pixel cel content is unique to each [Frame, Layer] intersection.
  • Adding a second frame to a static project seamlessly enables animation mode without data loss.
Constraints & Rules
  • Maximum frames per project: 64 frames.
  • Global FPS range: 1 to 30 FPS.
  • Per-frame duration override: 20ms to 5000ms.
  • Deleting a frame is disabled when only 1 frame remains.

3.3 Image-to-Pixel Art Converter

Conversion Pipeline
What It Does
Converts uploaded raster images into quantized, downscaled pixel art that can be edited directly as a project layer.
What Users Can Do
  • Upload a source image (PNG, JPG, WebP) via file picker or drag-and-drop.
  • Configure target pixel resolution, color count (2–64 colors) or target palette, pixelation intensity, and dithering mode (None, Bayer/Ordered, Floyd-Steinberg).
  • Compare changes in a live side-by-side or split-slider preview before applying.
  • Import the converted result as a new project or as a new layer in the active project.
  • Access the preserved original source image separately as a reference overlay or to re-run conversion with different parameters later.
Expected Behavior
  • Adjusting sliders recalculates the preview non-destructively from the preserved original image.
  • Importing into the editor automatically populates the project palette with the quantized colors.
Constraints & Rules
  • Supported formats: image/png, image/jpeg, image/webp.
  • Maximum file upload size: 10 MB; max source dimensions: 4096 x 4096 px.
  • Converted output resolution must fall within editor limits (8x8 to 512x512).

3.4 Community & Discovery

Gallery & Social
What It Does
Enables creators to publish finished artwork/animations to a public gallery and discover other creators' work.
What Users Can Do
  • Publish a project with Title, Description, Category, and up to 5 Tags.
  • Explore feeds sorted by Trending, Recent, or Following.
  • Search and filter artwork by keyword, category, tags, and format (All, Static Art, Animations).
  • View the Artwork Detail Page with crisp integer scaling, animation playback controls, extracted color palette swatches, and creator info.
  • Like, Comment on, and Bookmark posts; Follow other creators.
Expected Behavior
  • Publishing creates a public snapshot post. Subsequent edits to the workspace project remain private drafts until the owner clicks "Update Published Post".
Constraints & Rules
  • Authentication required for publishing, liking, commenting, bookmarking, and following.
  • Title: required, 3–80 chars; Description: optional, max 1,000 chars; Tags: max 5 tags (2–24 chars each).
  • Comments: plain text only, 1–500 chars, rate-limited to 5 per minute per user.

3.5 User and Project Management

Workspace & Auth
What It Does
Manages user authentication, personal project workspaces, draft lifecycles, and public creator profiles.
What Users Can Do
  • Register, log in, log out, and manage account settings.
  • Manage Drafts, Published Projects, Saved Source Images, and Bookmarks from the Personal Workspace.
  • Edit metadata, unpublish (revert to draft), or delete published posts.
  • Customize public creator profile (display name, avatar, bio) showcasing published creations.
Expected Behavior
  • When a guest user registers or logs in from the Studio, any active local project is automatically migrated to their cloud workspace.
Constraints & Rules
  • Username: unique, 3–24 characters (alphanumeric, _, -).
  • Bio: max 160 characters.
  • Maximum saved cloud projects per free account: 50.

05 Navigation Structure

The application separates browsing navigation from studio creation so the editor remains uncluttered:

  • Global Header (Community & Dashboard pages): Brand Logo (links to /), Search Input, Primary CTA (+ Create → /studio), Workspace link, and User Profile Menu.
  • Studio Header (Compact Mode in /studio): Collapses global navigation into a minimal home menu button so over 90% of the viewport is dedicated to the canvas, layers, palette, and timeline.

Public Discovery

06 Main User Flows

1. Creating First Pixel Art (New User)

  1. User lands on / and clicks Start Drawing (no account required).
  2. Studio opens with a 32x32 canvas and default starter palette.
  3. User draws with Pencil, Fill Bucket, and Shapes across 2 layers.
  4. User clicks Export → PNG (8x) for instant download, or clicks Save to register and auto-migrate the canvas to their cloud workspace.

2. Converting an Image to Pixel Art

  1. User opens Convert Image and uploads a PNG/JPG/WebP file.
  2. System stores the raw image separately and shows a live split preview.
  3. User adjusts target resolution (96x96), color count (24), and dithering.
  4. User clicks Import to Editor; converted pixels load onto an editable layer with extracted palette swatches and a toggleable reference image.

3. Creating and Exporting an Animation

  1. User expands the bottom Timeline Drawer in the Studio and duplicates Frame 1.
  2. User turns on Onion Skinning and redraws motion on Frames 2–6.
  3. User sets playback to 8 FPS and previews the loop in the Mini-Preview window.
  4. User clicks Export and downloads either an animated GIF or a PNG Sprite Sheet.

4. Saving a Project and Continuing Later

  1. Authenticated user edits a multi-layer project in /studio/:projectId.
  2. Studio auto-saves every 30s (or via Ctrl/Cmd+S), persisting layers, frames, cels, palette, and linked reference image.
  3. User returns later, opens /workspace, and selects the project card to resume with full state restored.

5. Publishing Artwork & Receiving Feedback

  1. User clicks Publish in the Studio and enters Title, Category, and Tags.
  2. System generates the public snapshot post at /art/:postId.
  3. Community members view the post, leave Likes and Comments, or Bookmark it.
  4. Creator can continue editing their private draft without affecting the live post until pushing an update.

6. Discovering & Interacting with Creators

  1. User filters / by Animations + tag #gameart, sorted by Trending.
  2. User opens an artwork detail page, inspects the frame playback and palette, and clicks the creator's profile.
  3. On /u/:username, user clicks Follow; future works appear in their Following feed.

08 Functional Requirements and Business Rules

1. Non-Destructive Source Image Preservation

Uploaded converter images are stored as independent SOURCE_IMAGE records. Editing or deleting converted pixel layers inside a PROJECT never mutates or overwrites the original uploaded file.

2. Draft vs. Published Isolation

A PROJECT holds editable layers and frames, while a POST holds a flattened public snapshot. Draft saves in the studio do not alter the live community post unless the creator explicitly triggers Update Published Post.

3. Guest-to-Registered Session Migration

Guests can draw, animate, convert images, and export locally without logging in. Signing up or logging in from the Studio automatically migrates the active local project to their cloud workspace.

4. Strict Pixel Integrity

All canvas viewports, gallery thumbnails, and detail views must render with nearest-neighbor scaling (image-rendering: pixelated) so pixel edges remain razor-sharp at every zoom level.

5. Ownership & Access Control

Draft projects and reference images are strictly private to PROJECT.user_id. Published posts are publicly readable; only the post owner can update/delete a post, and both the post owner and comment author can delete a comment.

6. Idempotent Social Interactions

Likes, Bookmarks, and Follows enforce composite uniqueness. Repeating an action toggles it off, and self-following (follower_id == following_id) is rejected.

09 MVP Scope vs. Future Enhancements

MVP Scope (Must-Have for v1)
  • Pixel Art Editor: 8x8–512x512 canvas, 7 core tools (Pencil, Eraser, Fill, Eyedropper, Line, Rectangle, Circle), custom palettes, zoom/pan/grid/mini-preview, 50-step undo/redo, up to 16 layers, cloud + local save, crisp PNG export.
  • Animation Editor: Up to 64 frames, add/duplicate/delete/reorder, global FPS (1–30) & frame duration overrides, onion skinning, GIF & PNG sprite sheet export.
  • Image Converter: PNG/JPG/WebP upload (≤10MB), resolution & color quantization (2–64 colors), dithering toggle, live split preview, import to editor, separate original preservation.
  • Community & Workspace: Auth, personal workspace (Drafts, Published, Reference Assets, Bookmarks), public profiles, Explore feed, search/tag filters, Likes, Comments, Bookmarks, and Follows.
Future Enhancements (Post-MVP)
  • Advanced Selection & Transform: Rectangular/lasso marquee selection, move/rotate/flip selection, symmetry/mirror drawing axes, and seamless tilemap mode.
  • Remixing & Collaboration: Opt-in "Allow Remix" flag to fork community artworks with attribution, and real-time multi-user canvas sessions.
  • Challenges & Curated Galleries: Daily/weekly themed prompts, restricted palette challenges, and user-curated collections.
  • Extended Formats & Notifications: .aseprite file import/export, MP4/WebM export, and real-time in-app notification center.
